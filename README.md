# Robux DevEx GBP Converter

A Chrome extension that converts Robux to GBP.

How it looks like:

<img width="153" height="40" alt="image" src="https://github.com/user-attachments/assets/59a67cb0-fcd3-4be5-a0bf-b9a7d54b9634" />


## Features

- Reads Robux / DevEx values
- Converts DevEx USD values into GBP and shows it next to robux balance
- Simple Chrome extension interface
- Uses Roblox-related data/APIs

## Tech Stack

- JavaScript
- HTML
- CSS
- Chrome Extensions API

## Installation

1. Clone this repository
2. Open `chrome://extensions`
3. Enable Developer Mode
4. Click "Load unpacked"
5. Select the extension folder
